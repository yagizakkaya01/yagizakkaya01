## 🧭 About Me

```yaml
name:      Yağız Akkaya
role:      Computer Engineering Student @ METU NCC
focus:     [ LLM Tool Calling & Agents, Retrieval-Augmented Generation, Computer Vision, Edge AI, Backends ]
```

I build systems that **see** and systems that **read** — computer vision models that run on constrained edge hardware, and LLM applications that let people ask questions of documents and databases they'd never have time to open. Lately that means **tool-calling agents**: the model picks a typed tool, the database or the document does the real work, and code checks the answer before anyone sees it.

Most of my work lives at the awkward, interesting seam between a model that works in a notebook and a system that survives real production environments: single-label datasets meeting multi-defect reality, detector jitter breaking naïve logic, GPU memory limits under concurrent ingestion, and high-throughput vector indexing. I measure what I ship with gold-set evaluations (held-out splits, honest failure counts) instead of quoting the best demo run.

### 🔬 flawscope
**Two-stage defect detection for aircraft-engine part metallography** *(private repo)*

Classifies optical-microscope cross-sections of machined aircraft-engine parts across **12 defect types** and returns a per-part verdict: *accept / rework / review / reject*. Most defect types have only a handful of examples, so it is built as a hybrid pipeline instead of one classifier.

- **Stage 1 — anomaly detection:** PatchCore / PaDiM trained on healthy images only; the heatmap is thresholded into candidate regions (connected components + NMS)
- **Stage 2 — two branches per region:** a CNN for types with enough samples and a prototype bank + WinCLIP text prompts for the rare ones, fused with Reciprocal Rank Fusion and Platt-calibrated to one probability scale
- **Safety-first decisions:** asymmetric per-type thresholds — a weak signal on an auto-reject type pulls in a human, while *accept* has to be earned; test-time augmentation disagreement routes to review

`Python` `PyTorch` `anomalib` `PatchCore` `open-clip` `OpenCV`
